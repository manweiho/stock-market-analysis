# Automotive Stock Performance Analysis Using Python
**Objective**
Analyze and compare 3 automotive companies using historical stock data to identify trends and investment insights.

**Methods**
- Data extraction via financial API
- Data cleaning using Pandas
- Time-series analysis (5-year trend)
- Moving average smoothing (100-day MA)
- Data visualization using Matplotlib

**Key Outputs**

- Comparative stock performance charts
- Volatility and trend analysis
- 1-year moving average analysis

**Conclusion**
Summary of investment recommendation based on observed performance trends.
